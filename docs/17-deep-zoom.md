# Satellite-style deep zoom

Scroll, pinch, or use **+ Zoom** to approach the Moon, up to 1,024x (about 6.8 km above the illustrative sphere). **Go to site** starts at 8x; zoom further to inspect it. Drag still orbits around the Moon. This is a smooth sphere with photographic detail, not a 3D terrain flight or a landing simulation.

The camera moves toward the surface above 1x. Its near plane follows altitude, and the fragment shader intersects an analytic sphere instead of magnifying coarse mesh triangles. CPU markers and GPU shading share the same camera distance and projection. The selected date's Sun/Earth directions, Hapke response, Earthshine and optional fill light remain in use.

NASA Moon Trek WMTS imagery streams only as visible quadtree patches need it. The global equirectangular `LRO_WAC_Mosaic_Global_303ppd_v02` matrix has 256px JPEG tiles, levels 0–8, top-left longitude/latitude (-180, 90), and dimensions `2^(z+1)` by `2^z`. Its finest angular spacing is about 83 m at the equator. The north/south `LRO_WAC_Mosaic_NPole60_100m_v02` and `LRO_WAC_Mosaic_SPole60_100m_v02` polar stereographic services supply the caps instead of the global mosaic's stretched polar rows. Those matrices have levels 0–5, origin (-1,095,930 m, +1,095,930 m), and pixel spacing `8561.953125 / 2^z` m; the valid square uses `2^z` rows and columns. Finest exposed polar spacing is about 268 m. These matrix values and anonymous CORS headers were checked against Trek's capabilities and tile responses.

The GPU retains at most 96 imagery tiles (24 MiB RGBA8), plus a 576×256 RGBA8 ancestor lookup table (0.563 MiB). Each surface pixel resolves its finest resident ancestor with one table lookup; the existing overview/polar material remains visible wherever no streamed tile is ready. One 256px image uploads per frame. Downloads and decoding run asynchronously, with bounded requests, decoded images and failure bookkeeping. Changing view discards stale completions; cached tiles can be reused. Failed imagery leaves the existing material available.

Photographs contain recorded shadows. Their contrast is combined with the dated lighting and is labeled in the globe; they are not calibrated albedo or live terrain shadows. Magnification beyond the source spacing enlarges existing pixels; it cannot reveal smaller features. Trek availability and browser/driver memory limits still apply. Scientific visibility calculations and terrain horizons are independent of these pictures.
